Задание
Разработать и запустить через Docker Compose веб-приложение, состоящее из двух сервисов:
web — веб-сервер (на выбор: Nginx или Node.js/Express), отдающий статическую страницу и обращающийся к БД. db — база данных PostgreSQL.

Приложение должно:
    - при открытии в браузере по адресу http://localhost:8080 отдавать HTML-страницу;
    - показывать текущее время и количество обращений, сохранённых в БД.

Часть 1. Разработка приложения и Dockerfile 
    Создайте структуру проекта:

        student-app/
        ├── app/
        │   ├── server.js
        │   ├── package.json
        │   └── public/
        │       └── index.html
        ├── Dockerfile
        ├── docker-compose.yml
        ├── init.sql
        └── .dockerignore

1.1. Реализуйте простое Node.js-приложение (server.js), которое: 
    - подключается к PostgreSQL (параметры берёт из переменных окружения DB_HOST, DB_USER, DB_PASSWORD, DB_NAME);
    - при запросе GET / возвращает HTML-страницу;
    - при запросе GET /api/visits увеличивает счётчик посещений в таблице visits и возвращает JSON { "count": N, "time": "..." }.

1.2. Напишите Dockerfile для сервиса web:
    - базовый образ — node:20-alpine;
    - рабочая директория /app;
    - скопируйте package.json и выполните npm install --production;
    - скопируйте исходники;
    - EXPOSE 3000;
    - CMD ["node", "server.js"].

1.3. Создайте .dockerignore, исключив node_modules и .git.

1.4. Напишите init.sql, который создаёт таблицу:

    sql
    CREATE TABLE IF NOT EXISTS visits (
    id SERIAL PRIMARY KEY,
    visited_at TIMESTAMP DEFAULT NOW()
    );

Часть 2. Настройка Docker Compose (25 минут)
    Опишите docker-compose.yml со следующими требованиями:
    версия Compose — современная (без устаревшего ключа version, либо 3.9);
        сервис db:
        - образ postgres:16-alpine;
        - переменные окружения POSTGRES_USER, POSTGRES_PASSWORD, POSTGRES_DB;
        - том db_data:/var/lib/postgresql/data для хранения данных;
        - монтирование ./init.sql:/docker-entrypoint-initdb.d/init.sql;
        - healthcheck через pg_isready.

        сервис web:
        - сборка из текущей директории (build: .);
        - порт 8080:3000;
        - переменные окружения для подключения к БД (DB_HOST=db и др.);
        - зависимость depends_on c условием service_healthy для db;
        - политика перезапуска restart: unless-stopped.
        - общая сеть (по умолчанию достаточно) и именованный том db_data.

Часть 3. Запуск и проверка (25 минут)
    Выполните последовательно и зафиксируйте результат:

        bash
        docker compose build
        docker compose up -d
        docker compose ps
        docker compose logs web
    
    Проверьте:
    - Открывается ли http://localhost:8080 — должна отобразиться HTML-страница.
    - Работает ли API: curl http://localhost:8080/api/visits — счётчик увеличивается при повторных вызовах.
    - Перезапустите контейнеры (docker compose restart) и убедитесь, что данные в БД сохранились (том работает).
    - Выполните docker compose down (без -v) и снова up -d — данные должны сохраниться.
    - Выполните docker compose down -v — том удалится, счётчик сбросится.
