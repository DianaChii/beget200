Наименование дисцилины:МДК 03.01 АДМИНИСТРИРОВАНИЕ СРЕД И ПЛАТФОРМ РАЗРАБОТКИ ИНФОРМАЦИОННЫХ РЕСУРСОВ

Наименование практики: НУстановка и настройка программного обеспечения для оркестрации контейнеров

ЦЕЛЬ РАБОТЫ
Изучить архитектуру систем оркестрации,
установить и настроить ПО для управления кластером контейнеров и проверить его
работоспособность.

ХОД РАБОТЫ

Вариант A. Docker Swarm

Задание 1. Кластер

    docker swarm init --advertise-addr <IP>
    docker swarm join-token worker            # для второй ноды
    docker node ls
    docker info | grep Swarm

Задание 2. Сервис

    docker service create --name web --replicas 3 -p 8080:80 nginx:alpine
    docker service ls && docker service ps web
    docker service inspect web --pretty


Задание 3. Масштабирование и self-healing

    docker service scale web=5
    docker kill <container>                    # Swarm поднимет новый
    docker service ps web


Задание 4. Rolling update и rollback

    docker service update --image nginx:1.25-alpine \
    --update-parallelism 1 --update-delay 10s web
    docker service rollback web


Задание 5. Секреты и конфиги

    echo "secret" | docker secret create db_pass -
    docker config create nginx_conf ./nginx.conf
    docker service create --name s --secret db_pass \
    --config source=nginx_conf,target=/etc/nginx/conf.d/default.conf \
    -p 8081:80 nginx:alpine
    docker exec <container> cat /run/secrets/db_pass


Задание 6. Overlay-сеть

    docker network create --driver overlay appnet
    docker service create --name a1 --network appnet nginx:alpine
    docker service create --name a2 --network appnet alpine sleep 3600
    docker exec <a2> ping -c2 a1


Задание 7. Стек

    docker stack deploy -c docker-compose.yml mystack
    docker stack services mystack
    docker stack ps mystack
    docker stack rm mystack


Задание 8. Ограничение ресурсов и placement

    docker service create --name lim --replicas 2 --limit-cpu 0.5 --limit-memory 128M \
    --constraint 'node.role==manager' nginx:alpine
    docker service ps lim


Задание 9. Healthcheck и откат при сбое

    docker service update --health-cmd "curl -f http://localhost/ || exit 1" \
    --health-interval 5s --health-retries 3 web


Задание 10. Выход из кластера

    docker service rm web s lim a1 a2
    docker swarm leave --force


Вариант B. k3s

Задание 1. Установка

    curl -sfL https://get.k3s.io | sh -
    systemctl status k3s
    kubectl get nodes && kubectl get pods -A

Задание 2. Pod и Deployment

    kubectl run nginx --image=nginx:alpine
    kubectl get pods && kubectl describe pod nginx && kubectl logs nginx
    kubectl create deployment web --image=nginx:alpine --replicas=3
    kubectl expose deployment web --port=80 --type=NodePort
    kubectl get svc web
    curl http://<IP>:<NodePort>


Задание 3. Масштабирование и self-healing

    kubectl scale deployment web --replicas=5
    kubectl delete pod <name>                  # ReplicaSet создаст новый
    kubectl get pods -w

Задание 4. YAML-манифесты

    kubectl get deployment web -o yaml > web.yaml
    kubectl apply -f web.yaml
    kubectl get all


Задание 5. Rolling update и rollback

    kubectl set image deployment/web nginx=nginx:1.25-alpine
    kubectl rollout status deployment/web
    kubectl rollout undo deployment/web
    kubectl rollout history deployment/web


Задание 6. ConfigMap и Secret

    kubectl create configmap nginx-conf --from-file=nginx.conf
    kubectl create secret generic db-pass --from-literal=password=s3cr3t
    kubectl describe configmap nginx-conf
    kubectl describe secret db-pass


Задание 7. Постоянное хранилище

    apiVersion: v1
    kind: PersistentVolumeClaim
    metadata: { name: data }
    spec:
    accessModes: [ReadWriteOnce]
    resources: { requests: { storage: 1Gi } }
    

    kubectl apply -f pvc.yaml
    kubectl get pvc
 

**Задание 8. Ограничения ресурсов.**
    
    kubectl set resources deployment web --limits=cpu=200m,memory=128Mi
    kubectl describe deployment web | grep -A3 Limits
    

**Задание 9. Namespace и квоты.**
   
    kubectl create namespace test
    kubectl run nginx2 --image=nginx:alpine -n test
    kubectl get pods -n test


**Задание 10. Очистка.**
 
    kubectl delete deployment web
    kubectl delete svc web
    kubectl delete namespace test
