**Дисциплина:** Разработка интерфейсов пользователя 
**Специальность:** 09.02.09 Веб-разработка  
**Тема:** Работа с компонентами  
**Время выполнения:** 4 академических часа 

### Цель работы
Научиться создавать высокодетализированный (High-Fidelity) интерактивный прототип веб-интерфейса, используя систему компонентов, вариантов и свойств в бесплатной версии Figma. Закрепить знания о видах прототипирования по уровню детализации и способу взаимодействия с пользователем (согласно пп. 7–8 лекционных материалов).

### Требования к ПО
*   Figma (Free / Starter Plan). *Все используемые функции (Components, Variants, Properties, Prototyping) доступны бесплатно.*
*   Браузер или десктопное приложение Figma.

Задание 1

1.  **Постановка задачи (5 мин):**  
    Вам необходимо создать интерактивный прототип лендинга для онлайн-курса «Основы веб-разработки». Прототип должен быть кликабельным (интерактивным) и содержать минимум 3 экрана: Главная, Каталог курсов, Страница курса.
2.  **Настройка файла (10 мин):**  
    *   Создайте новый файл. Переименуйте страницу в `Практическая_работа`.
    *   Создайте фреймы: `Desktop_Main` (1440×1024), `Desktop_Catalog`, `Desktop_Course`.
    *   Настройте сетку (Layout Grid): Columns = 12, Margin = 80px, Gutter = 20px.
3.  **Создание токенов и типографики (10 мин):**  
    *   Создайте стили цветов (Color Styles): `Primary_Blue (#2563EB)`, `Text_Dark (#1F2937)`, `BG_Light (#F9FAFB)`.
    *   Создайте текстовые стили: `H1_Inter_Bold_48`, `H2_Inter_SemiBold_32`, `Body_Inter_Regular_16`.
4.  **Базовый компонент кнопки (20 мин):**  
    *   Нарисуйте кнопку с Auto Layout (`Shift+A`).
    *   Преобразуйте в Главный компонент (`Ctrl+Alt+K`). Назовите: `Button/Primary`.
    *   Создайте Варианты: `State=Default`, `State=Hover`, `State=Pressed`, `State=Disabled`.
    *   Добавьте Текстовое свойство: `Label`.
    *   Добавьте Булево свойство: `Icon_Right` (добавьте иконку стрелки внутрь компонента и свяжите её с булевым свойством).

> **⚠️ Важно для Free Plan:** Не создавайте отдельные страницы для UI Kit. Все компоненты размещайте на той же странице, что и макеты, чтобы не тратить лимит на количество страниц и файлов. Используйте локальные стили и переменные (Variables доступны в Free Plan для Color и Number).

Задание 2

1.  **Компонент карточки курса (20 мин):**  
    *   Создайте компонент `Card/Course`. Внутри используйте Auto Layout (Vertical).
    *   Добавьте изображение-заглушку (Placeholder), заголовок, описание, цену и кнопку.
    *   Кнопку внутри карточки используйте как **Экземпляр** компонента `Button/Primary`.
    *   Создайте Варианты карточки: `Type=Standard`, `Type=Featured` (выделенная рамкой).
    *   Добавьте свойство `Course_Title` (текст) и `Price` (текст).
2.  **Компонент навигации (Header) (15 мин):**  
    *   Создайте компонент `Nav/Header`.
    *   Включите логотип, пункты меню и кнопку «Войти» (экземпляр Button).
    *   Используйте Auto Layout для адаптивности отступов.
3.  **Верстка экранов (10 мин):**  
    *   Соберите экран `Desktop_Main`: Header + Hero-секция + Секция популярных курсов (3 экземпляра Card/Course).
    *   Соберите экран `Desktop_Catalog`: Header + Фильтры (упрощенно) + Сетка из 6 карточек.
    *   Соберите экран `Desktop_Course`: Header + Детальная информация + CTA-блок.

Задание 3

1.  **Переход между экранами (15 мин):**  
    *   Перейдите во вкладку **Prototype**.
    *   Свяжите кнопку «Смотреть курсы» на Главной → экран Catalog.
    *   Свяжите каждую карточку на экране Catalog → экран Course.
    *   Настройте переход: `On Click` → `Navigate to` → Animation: `Smart Animate`, Duration: 300ms, Easing: Ease Out.
2.  **Микровзаимодействия компонентов (20 мин):**  
    *   Настройте взаимодействие вариантов кнопки: `While Hovering` → Change to `State=Hover`; `While Pressing` → Change to `State=Pressed`.
    *   Настройте взаимодействие карточки: `While Hovering` → Smart Animate (легкое поднятие вверх + тень).
    *   *Проверка:* Убедитесь, что микроанимации работают внутри экземпляров без дополнительных настроек на каждом экране.
3.  **Фиксация хедера и скролл (10 мин):**  
    *   Выделите Header на всех экранах → Prototype → Position: `Fixed when scrolling`.
    *   Настройте вертикальный скролл для контента внутри фреймов (Overflow: Vertical).

> **💡 Совет для Free Plan:** Функция Smart Animate работает бесплатно. Избегайте использования Advanced Prototyping (условная логика, переменные в прототипе) — они требуют платной подписки. Ограничьтесь классическими переходами и состояниями компонентов.

Задание 4

1.  **Презентация прототипа (15 мин):**  
    *   Нажмите кнопку **Present** (▶) в правом верхнем углу.
    *   Прокликайте весь пользовательский сценарий: Главная → Каталог → Карточка курса → Возврат назад.
    *   Проверьте все hover/press состояния кнопок.
    *   Зафиксируйте найденные ошибки (например, неработающая ссылка, съехавший Auto Layout).
2.  **Исправление ошибок (15 мин):**  
    *   Вернитесь в режим редактирования и исправьте недочёты.
    *   Убедитесь, что все изменения в Главных компонентах корректно применились ко всем экземплярам.
3.  **Подготовка отчёта (15 мин):**  
    *   Сделайте скриншот панели **Assets** с видимыми компонентами и вариантами.
    *   Сделайте скриншот вкладки **Prototype** с видимыми связями между фреймами.
    *   Скопируйте ссылку на файл (Share → Anyone with the link → Can view).
